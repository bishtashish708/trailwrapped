# Contributing

Thanks for taking a look. This project is early, so there's a lot of room to shape it.

## Ways to help

- Report bugs or weird behavior in an issue
- Suggest a stat or recap idea that's missing
- Build a plugin/module once the plugin interface lands (see ROADMAP.md)
- Improve docs, especially setup instructions on platforms other than what I've tested

## Working on the code

1. Fork the repo and clone your fork
2. Create a branch for your change
3. Keep PRs focused on one thing, easier to review that way
4. Open a PR with a short description of what changed and why

## Ground rules

- Be respectful in issues and PRs
- No feature that requires sending user activity data to a third-party server without the user explicitly opting in
- If you're adding a dependency, have a reason for it

Open an issue first for anything big (new data source, architecture change) so we can talk it through before you sink time into it.
